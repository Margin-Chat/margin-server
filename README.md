# margin-server

Spring Boot backend for [margin](https://margin.chat). Handles REST, WebSocket, auth, storage, subscriptions, and SFU coordination.

## Building

```bash
./mvnw clean package
```

## Running locally

```bash
./mvnw spring-boot:run
```

Dev defaults are in `application-dev.yml`.

## Tests

```bash
./mvnw test
```
